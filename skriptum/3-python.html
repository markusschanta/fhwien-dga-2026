1. Python im Überblick

Python ist eine universell einsetzbare Programmiersprache. Die erste Version veröffentlichte der niederländische Informatiker Guido van Rossum im Jahr 1991; der Name geht auf die britische Comedy-Gruppe Monty Python zurück, nicht auf die Schlange. Python ist Open Source und kostenlos verfügbar und wird von der gemeinnützigen Python Software Foundation betreut.

Die heute verwendete Hauptversion Python 3 existiert seit 2008; jährlich erscheint eine neue Unterversion. Die frühere Version Python 2 wird seit 2020 nicht mehr unterstützt. Python ist eine interpretierte Sprache: Der Code wird Anweisung für Anweisung ausgeführt, ohne zuvor vollständig übersetzt zu werden.

Eingesetzt wird Python vor allem in der Datenanalyse, in der künstlichen Intelligenz und im maschinellen Lernen, zur Automatisierung von Arbeitsabläufen sowie für Webanwendungen. Seit Jahren zählt Python zu den meistverwendeten Programmiersprachen weltweit.

Dass Python interpretiert wird, ist für die Arbeit in Notebooks von Bedeutung: Jede Codezelle wird unmittelbar ausgeführt, und ihr Ergebnis steht sofort zur Verfügung (Abschnitt 4.1).

2. Warum Python?

Kapitel 2 behandelte die Abfrage von Datenbanken mit SQL. Eine Abfrage beantwortet jeweils eine konkrete Frage. In der Praxis umfasst eine Analyse jedoch häufig mehrere Arbeitsschritte: Daten aus einer Datenbank und einer Excel-Datei werden zusammengeführt, Fehler bereinigt, Kennzahlen berechnet und Diagramme erstellt, und dieser Ablauf wiederholt sich oft in regelmäßigen Abständen. Für derartige Abläufe eignet sich eine Programmiersprache.

Python ist hierfür besonders verbreitet, und zwar aus folgenden Gründen:

  • Python gilt als gut lesbar; der Code ähnelt einer Beschreibung in natürlicher Sprache.
  • Für Python steht ein umfangreiches Angebot an Bibliotheken zur Verfügung, also an vorgefertigten Erweiterungen, etwa pandas für Tabellen (Kapitel 4) und altair für Diagramme (Kapitel 5).
  • Python ist plattformunabhängig und läuft auf Arbeitsplatzrechnern, auf Servern und im Browser.
  • Einmal programmierte Abläufe lassen sich beliebig oft ausführen. Wiederkehrende Arbeitsschritte, die sonst manuell in Excel erfolgen, werden durch das erneute Ausführen des Codes ersetzt.

Ziel dieses Kapitels ist keine Ausbildung in Softwareentwicklung. Vermittelt werden die Grundbausteine, mit denen sich kleinere Aufgaben eigenständig lösen lassen und mit denen sich Code aus IT- und BI-Abteilungen lesen und nachvollziehen lässt.

3. Notebooks in Google Colab

In der Lehrveranstaltung wird Python in Google Colab verwendet, einer kostenlosen Entwicklungsumgebung im Browser. Erforderlich ist lediglich ein Google-Konto; eine Installation ist nicht notwendig. Colab arbeitet mit Notebooks, also Dokumenten, in denen sich Text, Code und Ergebnisse abwechseln.

  • Eine Textzelle enthält Erläuterungen, Überschriften und Aufgabenstellungen.
  • Eine Codezelle enthält Python-Code. Sie wird mit Shift + Enter oder über die Schaltfläche ▶ ausgeführt; das Ergebnis erscheint unmittelbar darunter.
  • Maßgeblich ist die Reihenfolge der Ausführung, nicht die Reihenfolge im Dokument. Eine Variable existiert erst, nachdem die Zelle mit ihrer Zuweisung ausgeführt wurde.
  • Damit eigene Änderungen erhalten bleiben, ist das Notebook über Datei, Kopie in Drive speichern im eigenen Google Drive abzulegen.
  • Bei unerwartetem Verhalten empfiehlt es sich, die Sitzung über Laufzeit, Sitzung neu starten zurückzusetzen und die Zellen in der Reihenfolge des Dokuments erneut auszuführen.

Zu diesem Kapitel steht ein Übungsnotebook in Colab zur Verfügung. Es folgt dem Aufbau dieses Skriptums und enthält Aufgaben mit Testzellen, die die Richtigkeit einer Lösung unmittelbar überprüfen, sowie die Lösungen in eingeklappten Zellen. Sämtliche Beispiele dieses Skriptums lassen sich in eine Codezelle übernehmen und ausführen.

Text nach dem Zeichen # ist ein Kommentar. Python ignoriert Kommentare; sie dienen ausschließlich der Erläuterung des Codes. Die Funktion print() gibt Werte aus:

# Das ist ein Kommentar
print("Hallo, Colab!")
print(3 + 4)

Ausgabe:

Hallo, Colab!
7

4. Variablen

Eine Variable speichert einen Wert unter einem Namen. Das Gleichheitszeichen bezeichnet eine Zuweisung: Zunächst wird der Ausdruck auf der rechten Seite ausgewertet, anschließend wird das Ergebnis unter dem Namen auf der linken Seite gespeichert.

preis = 19.50
menge = 3
umsatz = preis * menge
print(umsatz)

Ausgabe:

58.5

Einer Variable kann jederzeit ein neuer Wert zugewiesen werden. Daher ist auch summe = summe + 1 zulässig, obwohl der Ausdruck als mathematische Gleichung keinen Sinn ergäbe: Auf der rechten Seite wird mit dem bisherigen Wert gerechnet, auf der linken Seite wird der neue Wert gespeichert.

bestellungen = 9
bestellungen = bestellungen + 1
print(bestellungen)

Ausgabe:

10

4.1. Reihenfolge der Anweisungen

Python führt Anweisungen der Reihe nach aus und speichert dabei den aktuellen Wert jeder Variable. Dieser Zustand verändert sich mit jeder Zuweisung. Eine Variable behält ihren Wert so lange, bis ihr ein neuer Wert zugewiesen wird; sie wird nicht automatisch neu berechnet, wenn sich eine andere Variable ändert:

preis = 20
menge = 3
umsatz = preis * menge
menge = 5
print(umsatz)

umsatz = preis * menge
print(umsatz)

Ausgabe:

60
100

Die folgende Darstellung zeigt den Inhalt der Variablen nach jeder Anweisung. Lila hervorgehoben ist jeweils der neu zugewiesene Wert, grau die Werte, die unverändert bestehen bleiben; ein leeres Feld bedeutet, dass die Variable noch nicht existiert.

preismengeumsatz
preis = 2020
menge = 3203
umsatz = preis * menge20360
menge = 520560
umsatz = preis * menge205100

neuer Wertbleibt erhalten

Nach Schritt 4 enthält umsatz weiterhin den Wert 60, obwohl sich menge geändert hat. Erst die erneute Zuweisung in Schritt 5 berechnet den Umsatz mit dem neuen Wert. In Tabellenkalkulationen wie Excel werden Formeln dagegen automatisch neu berechnet; in Python ist dafür eine eigene Anweisung erforderlich.

In Colab gilt dasselbe Prinzip für Zellen: Maßgeblich ist die Reihenfolge, in der die Zellen ausgeführt werden, nicht ihre Position im Notebook. Wird eine Zelle weiter oben nachträglich geändert und erneut ausgeführt, ändern sich die Ergebnisse darunterliegender Zellen erst, wenn auch diese erneut ausgeführt werden.

Regeln für Namen
  • Zulässig sind Buchstaben, Ziffern und der Unterstrich _; ein Name darf nicht mit einer Ziffer beginnen.
  • Python unterscheidet zwischen Groß- und Kleinschreibung: umsatz und Umsatz bezeichnen zwei verschiedene Variablen.
  • Gebräuchlich sind Kleinbuchstaben, Wörter werden durch Unterstriche getrennt, etwa umsatz_gesamt.
  • Aussagekräftige Namen beschreiben den Inhalt: bestellwert ist verständlicher als x.
  • Schlüsselwörter wie if, for oder def dürfen nicht als Namen verwendet werden.

5. Datentypen

Jeder Wert besitzt einen Datentyp, der festlegt, welche Operationen mit ihm möglich sind. Die vier grundlegenden Datentypen sind:

Für Zahlen stehen die üblichen arithmetischen Operatoren zur Verfügung. Eine Division mit / ergibt stets eine Kommazahl.

5.2. Text

Texte lassen sich mit + verketten. len() ermittelt die Anzahl der Zeichen, .upper() und .lower() wandeln in Groß- bzw. Kleinbuchstaben um:

stadt = "Graz"
land = "Austria"
print(stadt + ", " + land)
print(len(land), land.upper(), land.lower())

Ausgabe:

Graz, Austria
7 AUSTRIA austria

5.3. Umwandeln

Daten aus Formularen oder Dateien liegen häufig als Text vor, auch wenn sie Zahlen darstellen. Mit int(), float() und str() werden Werte in den jeweiligen Datentyp umgewandelt:

budget_text = "1250"          # Text, z. B. aus einem Webformular
budget = int(budget_text)      # jetzt eine Zahl
print(budget + 250)
print(float("19.90") * 2)
print("Jahr " + str(2026))

Ausgabe:

1500
39.8
Jahr 2026

5.4. Ausgabe mit print

Texte werden mit + verbunden; Zahlen sind dafür zuvor mit str() in Text umzuwandeln. Alternativ gibt print() mehrere Werte, durch Kommas getrennt, nebeneinander aus. Für eine übersichtliche Ausgabe von Kommazahlen empfiehlt sich round():

kunde = "Ernst Handel"
anzahl = 10
umsatz = 4235.456
print(kunde + " hat " + str(anzahl) + " Bestellungen.")
print("Umsatz:", round(umsatz, 2), "EUR")

Ausgabe:

Ernst Handel hat 10 Bestellungen.
Umsatz: 4235.46 EUR

7. Listen

Eine Liste speichert mehrere Werte in einer festgelegten Reihenfolge. Sie wird in eckigen Klammern notiert, die Werte werden durch Kommas getrennt. Der Zugriff auf einzelne Werte erfolgt über den Index in eckigen Klammern. Der erste Wert besitzt den Index 0; negative Indizes zählen vom Ende der Liste.

bestellwerte = [120.5, 89.9, 230.0, 45.0]
print(bestellwerte[0])     # erster Wert
print(bestellwerte[-1])    # letzter Wert
print(bestellwerte[1:3])   # Ausschnitt: Index 1 bis vor 3
print(len(bestellwerte))   # Anzahl der Werte

Ausgabe:

120.5
45.0
[89.9, 230.0]
4

Für Listen mit Zahlen stehen vordefinierte Funktionen zur Verfügung. sorted() liefert eine sortierte Kopie, mit reverse=True in absteigender Reihenfolge:

print(sum(bestellwerte), min(bestellwerte), max(bestellwerte))
print(sorted(bestellwerte))
print(sorted(bestellwerte, reverse=True))

Ausgabe:

485.4 45.0 230.0
[45.0, 89.9, 120.5, 230.0]
[230.0, 120.5, 89.9, 45.0]

.append() fügt einen Wert am Ende der Liste hinzu, in prüft, ob ein Wert in der Liste enthalten ist:

warenkorb = ["Chai", "Chang"]
warenkorb.append("Tofu")
print(warenkorb)
print("Tofu" in warenkorb)

Ausgabe:

['Chai', 'Chang', 'Tofu']
True
Hinweis zum Index

Da der Index bei 0 beginnt, umfasst eine Liste mit vier Werten die Indizes 0 bis 3. Ein Zugriff auf bestellwerte[4] führt daher zu einem IndexError.

8. Dictionaries

Ein Dictionary speichert Schlüssel-Wert-Paare. Es wird in geschweiften Klammern notiert, Schlüssel und Wert sind jeweils durch einen Doppelpunkt getrennt. Der Zugriff erfolgt nicht über eine Position, sondern über den Schlüssel:

kunde = {"name": "Ernst Handel", "stadt": "Graz", "land": "Austria"}
print(kunde["stadt"])

Ausgabe:

Graz

Über den Schlüssel lassen sich Werte ändern und neue Paare hinzufügen:

kunde["bestellungen"] = 10       # neues Paar
kunde["stadt"] = "Graz-Puntigam"  # Wert ändern
print(kunde)

Ausgabe:

{'name': 'Ernst Handel', 'stadt': 'Graz-Puntigam', 'land': 'Austria', 'bestellungen': 10}

Ein Dictionary entspricht einer Zeile einer Tabelle, die Schlüssel entsprechen den Spaltennamen. Eine Liste von Dictionaries entspricht folglich einer vollständigen Tabelle:

kunden = [
    {"name": "Ernst Handel", "stadt": "Graz", "land": "Austria"},
    {"name": "Piccolo und mehr", "stadt": "Salzburg", "land": "Austria"},
    {"name": "Alfreds Futterkiste", "stadt": "Berlin", "land": "Germany"},
]
print(kunden[1]["stadt"])

Ausgabe:

Salzburg

Dieselben Daten in tabellarischer Darstellung:

namestadtland
Ernst HandelGrazAustria
Piccolo und mehrSalzburgAustria
Alfreds FutterkisteBerlinGermany

Auf derartigen Strukturen baut die Bibliothek pandas auf, die in Kapitel 4 behandelt wird und den Umgang mit Tabellen wesentlich vereinfacht.

9. Verzweigungen: if, elif, else

Eine Verzweigung bewirkt, dass Code nur ausgeführt wird, wenn eine Bedingung erfüllt ist. elif („else if“) prüft weitere Bedingungen, else kommt zur Anwendung, wenn keine der Bedingungen zutrifft. Die Bedingungen werden von oben nach unten geprüft; ausgeführt wird ausschließlich der Block der ersten zutreffenden Bedingung.

bestellwert = 180

if bestellwert >= 200:
    rabatt = 0.10
elif bestellwert >= 100:
    rabatt = 0.05
else:
    rabatt = 0

print("Rabatt:", rabatt * 100, "%")

Ausgabe:

Rabatt: 5.0 %
Doppelpunkt und Einrückung

Nach jeder Bedingung sowie nach else steht ein Doppelpunkt. Der davon abhängige Code wird eingerückt, üblicherweise um vier Leerzeichen. Die Einrückung ist in Python Bestandteil der Syntax: Sie legt fest, welcher Code zu welcher Bedingung gehört. Colab rückt nach einem Doppelpunkt automatisch ein.

Die Reihenfolge der Bedingungen ist daher von Bedeutung. Stünde bestellwert >= 100 an erster Stelle, erhielte auch eine Bestellung über 250 lediglich 5 % Rabatt, da der Block der ersten zutreffenden Bedingung ausgeführt wird.

Mehrere Bedingungen lassen sich mit and und or verknüpfen:

land = "Austria"
bestellwert = 120

if land == "Austria" and bestellwert > 100:
    print("Gutschein über 10 EUR")
else:
    print("kein Gutschein")

Ausgabe:

Gutschein über 10 EUR

10. Schleifen: for

Eine for-Schleife führt einen Codeblock für jedes Element einer Liste einmal aus. Die Variable nach for nimmt dabei nacheinander den Wert jedes Elements an. Auch hier sind Doppelpunkt und Einrückung erforderlich.

bestellwerte = [120.5, 89.9, 230.0, 45.0]

for wert in bestellwerte:
    print("Bestellung über", wert, "EUR")

Ausgabe:

Bestellung über 120.5 EUR
Bestellung über 89.9 EUR
Bestellung über 230.0 EUR
Bestellung über 45.0 EUR

Der Name dieser Variable ist frei wählbar. Gebräuchlich ist die Einzahl des Listennamens, etwa for kunde in kunden oder for preis in preise.

10.1. Grundmuster: Aufsummieren und Zählen

Vor der Schleife wird eine Variable mit dem Wert 0 angelegt; innerhalb der Schleife wird der jeweilige Wert hinzugezählt:

summe = 0
anzahl_gross = 0
for wert in bestellwerte:
    summe = summe + wert
    if wert > 100:
        anzahl_gross = anzahl_gross + 1
print(summe, anzahl_gross)

Ausgabe:

485.4 2

10.2. Grundmuster: Filtern

Vor der Schleife wird eine leere Liste angelegt. Innerhalb der Schleife prüft eine if-Anweisung jedes Element; zutreffende Elemente werden der Liste hinzugefügt:

grosse_bestellungen = []
for wert in bestellwerte:
    if wert > 100:
        grosse_bestellungen.append(wert)
print(grosse_bestellungen)

Ausgabe:

[120.5, 230.0]

Angewendet auf eine Liste von Dictionaries entspricht dieses Muster einer WHERE-Bedingung in SQL:

namen_at = []
for kunde in kunden:
    if kunde["land"] == "Austria":
        namen_at.append(kunde["name"])
print(namen_at)

Ausgabe:

['Ernst Handel', 'Piccolo und mehr']

10.3. Zahlenfolgen mit range

range(n) erzeugt die Zahlen von 0 bis n minus 1, range(a, b) die Zahlen von a bis b minus 1. Damit lässt sich ein Codeblock eine festgelegte Anzahl von Malen wiederholen:

for monat in range(1, 4):
    print("Report für Monat", monat)

Ausgabe:

Report für Monat 1
Report für Monat 2
Report für Monat 3

Daneben existiert die while-Schleife, die ausgeführt wird, solange eine Bedingung erfüllt ist. Für die Aufgaben dieser Lehrveranstaltung ist die for-Schleife ausreichend.

11. Funktionen

Eine Funktion fasst Code unter einem Namen zusammen, sodass er mehrfach verwendet werden kann. Einige Funktionen wie print(), len() oder sum() sind in Python bereits enthalten. Eigene Funktionen werden mit def definiert:

def brutto(netto):
    return netto * 1.2

print(brutto(100))
print(brutto(250))

Ausgabe:

120.0
300.0
  • Auf def folgen der Name der Funktion und in Klammern die Parameter, also die Eingabewerte, anschließend ein Doppelpunkt und der eingerückte Codeblock.
  • Mit return gibt die Funktion ein Ergebnis zurück; die Ausführung der Funktion endet an dieser Stelle.
  • Beim Aufruf werden den Parametern konkrete Werte übergeben, etwa brutto(100).

Eine Funktion kann mehrere Parameter besitzen sowie Verzweigungen und Schleifen enthalten:

def versandkosten(bestellwert, land):
    if land == "Austria" and bestellwert >= 50:
        return 0
    elif land == "Austria":
        return 4.90
    else:
        return 9.90

print(versandkosten(35, "Austria"))
print(versandkosten(80, "Austria"))
print(versandkosten(80, "Germany"))

Ausgabe:

4.9
0
9.9

11.1. return und print

Ein häufiger Fehler besteht darin, print anstelle von return zu verwenden. print gibt einen Wert lediglich aus; das Ergebnis der Funktion ist dann None („kein Wert“) und kann nicht weiterverwendet werden:

def brutto_falsch(netto):
    print(netto * 1.2)

ergebnis = brutto_falsch(100)
print(ergebnis)

Ausgabe:

120.0
None

11.2. Funktionen testen

Die Korrektheit einer Funktion wird mit Testfällen überprüft: Für eine bestimmte Eingabe ist das erwartete Ergebnis bekannt und wird mit dem tatsächlichen Ergebnis verglichen. Die folgende Funktion check_result wird auch in den Gruppenübungen verwendet:

def check_result(i, expected_result, actual_result):
  print("Input: " + str(i))
  print("Expected result: " + str(expected_result))
  print("Actual result: " + str(actual_result))
  if expected_result == actual_result:
    print("✅ OK! (actual result == expected result)")
  else:
    print("❌ ERROR! (actual result != expected result)")
  print()

check_result(80, 0, versandkosten(80, "Austria"))
check_result(50, 0, versandkosten(50, "Austria"))

Ausgabe:

Input: 80
Expected result: 0
Actual result: 0
✅ OK! (actual result == expected result)

Input: 50
Expected result: 0
Actual result: 0
✅ OK! (actual result == expected result)

Aussagekräftige Testfälle berücksichtigen auch Grenzfälle, etwa einen Wert genau an einer Grenze (hier 50), eine leere Liste, den Wert 0 oder unerwartete Eingaben.

12. Fehlermeldungen lesen

Fehlermeldungen geben Aufschluss über die Ursache eines Problems. Sie umfassen häufig mehrere Zeilen; entscheidend ist die letzte Zeile, die die Art des Fehlers und in der Regel auch dessen Ursache angibt. Drei Fehlerarten treten besonders häufig auf:

umsatz_gesamt = 1500
print(umsatz_gesammt)

Fehlermeldung (letzte Zeile):

NameError: name 'umsatz_gesammt' is not defined. Did you mean: 'umsatz_gesamt'?

Ein NameError zeigt an, dass ein Name nicht bekannt ist, etwa aufgrund eines Tippfehlers oder weil die Zelle mit der Zuweisung noch nicht ausgeführt wurde.

bestellungen = 10
print("Anzahl Bestellungen: " + bestellungen)

Fehlermeldung (letzte Zeile):

TypeError: can only concatenate str (not "int") to str

Ein TypeError zeigt an, dass die verwendeten Werte nicht kompatibel sind, hier Text und Zahl. Abhilfe schafft die Umwandlung mit str(bestellungen) oder die Ausgabe mehrerer Werte mit Komma: print("Anzahl Bestellungen:", bestellungen).

bestellwert = 80
if bestellwert > 50
    print("Gratisversand")

Fehlermeldung (letzte Zeile):

SyntaxError: expected ':'

Ein SyntaxError zeigt an, dass die Schreibweise nicht den Regeln der Sprache entspricht; im Beispiel fehlt der Doppelpunkt. Fehlt die Einrückung, meldet Python einen IndentationError.

13. SQL aus Python

Python kann unmittelbar auf Datenbanken zugreifen. In den Gruppenübungen wird die Beispieldatenbank aus Kapitel 2 in Colab geladen. Die folgende Zelle lädt die Daten aus dem Internet und stellt die Datenbank in der Variable db bereit:

from urllib.request import urlopen
import sqlite3

GITHUB_URL = "https://raw.githubusercontent.com/markusschanta/w3schools-database/refs/heads/master/w3schools.sqllite.sql"
create_sql = urlopen(GITHUB_URL).read().decode()

db = sqlite3.connect(":memory:")
db.executescript(create_sql)

import lädt eine Bibliothek. Die Funktion pd.read_sql_query der Bibliothek pandas führt eine Abfrage aus und liefert das Ergebnis als Tabelle, als sogenannten DataFrame. Dreifache Anführungszeichen ermöglichen Texte über mehrere Zeilen:

import pandas as pd

SQL = """
SELECT Country, COUNT(*) AS Kunden
FROM customers
GROUP BY Country
ORDER BY Kunden DESC
"""
ergebnis = pd.read_sql_query(SQL, db)

Ergebnis (21 Zeilen, hier die ersten fünf):

Die Datenbank in Colab entspricht dem unveränderten SQLite-Original. Im Unterschied zum SQL-Editor der Lehrveranstaltung gilt:

  • Die Tabellennamen werden klein geschrieben; die Bestellpositionen heißen order_details statt OrderDetails.
  • Bei Text wird zwischen Groß- und Kleinschreibung unterschieden: WHERE Country = 'Austria' liefert 2 Kunden, 'austria' liefert 0.
  • Anstelle von TOP wird LIMIT am Ende der Abfrage verwendet.
  • Eine Spalte, die weder im GROUP BY steht noch aggregiert wird, führt nicht zu einem Fehler, sondern zu einem beliebigen Wert (Kapitel 2, Abschnitt 10.1). Diese Regel ist daher eigenverantwortlich zu beachten.

Kapitel 4 setzt mit pandas fort: Tabellen werden geladen, gefiltert, gruppiert und verknüpft, analog zu SQL, jedoch in Python.

14. Praxisbeispiel: Newsletter vorbereiten

Das folgende Beispiel verbindet die behandelten Bausteine. Ein Newsletter soll an Kunden in Österreich und Deutschland versendet werden, jeweils mit einem passenden Betreff: Kunden ohne bisherige Bestellung erhalten ein Willkommensangebot, Stammkunden mit mindestens zehn Bestellungen ein Dankeschön, alle übrigen einen Hinweis auf neue Produkte. Die Daten stammen aus der Beispieldatenbank.

kunden = [
    {"name": "Ernst Handel", "kontakt": "Roland Mendel", "land": "Austria", "bestellungen": 10},
    {"name": "Piccolo und mehr", "kontakt": "Georg Pipps", "land": "Austria", "bestellungen": 3},
    {"name": "Alfreds Futterkiste", "kontakt": "Maria Anders", "land": "Germany", "bestellungen": 0},
    {"name": "Around the Horn", "kontakt": "Thomas Hardy", "land": "UK", "bestellungen": 2},
]

def betreff(kunde):
    if kunde["bestellungen"] == 0:
        return "Willkommen, " + kunde["kontakt"] + ": 10 % auf die erste Bestellung"
    elif kunde["bestellungen"] >= 10:
        return "Danke für Ihre Treue, " + kunde["kontakt"] + "!"
    else:
        return "Neu im Sortiment, " + kunde["kontakt"]

for kunde in kunden:
    if kunde["land"] in ["Austria", "Germany"]:
        print(betreff(kunde))

Ausgabe:

Danke für Ihre Treue, Roland Mendel!
Neu im Sortiment, Georg Pipps
Willkommen, Maria Anders: 10 % auf die erste Bestellung

Die Liste von Dictionaries enthält die Daten, die Funktion bestimmt mit einer Verzweigung den Betreff, und die Schleife durchläuft alle Kunden und filtert nach Land. Around the Horn aus Großbritannien erhält daher keinen Newsletter. In der Praxis würden die Kundendaten per SQL aus der Datenbank abgefragt und die Texte an ein Newsletter-System übergeben; der Aufbau bliebe derselbe.

18. Begriffe

Bibliothek (Library)
Fertige Sammlung von Funktionen, die mit import geladen wird, etwa pandas.
Codezelle
Bereich in einem Notebook mit ausführbarem Python-Code; das Ergebnis erscheint darunter.
DataFrame
Tabelle in der Bibliothek pandas; Ergebnis von pd.read_sql_query.
Datentyp
Art eines Werts, etwa int, float, str oder bool.
Dictionary
Sammlung von Schlüssel-Wert-Paaren in geschweiften Klammern; entspricht einer Tabellenzeile.
Einrückung
Leerzeichen am Zeilenanfang; legt fest, welcher Code zu einer Bedingung, Schleife oder Funktion gehört.
Funktion
Benannter Codeblock mit Parametern, der mit return ein Ergebnis liefert.
Index
Position eines Werts in einer Liste, beginnend bei 0.
Liste
Geordnete Sammlung von Werten in eckigen Klammern.
Notebook
Dokument aus Text- und Codezellen, etwa in Google Colab.
Parameter
Eingabe einer Funktion, in Klammern nach dem Funktionsnamen.
Schleife
Code, der für jedes Element einer Liste (for) wiederholt wird.
Testfall
Eingabe mit bekanntem erwarteten Ergebnis, um eine Funktion zu prüfen.
Variable
Name, unter dem ein Wert gespeichert wird.
Verzweigung
Code, der nur unter einer Bedingung ausgeführt wird (if, elif, else).
