Der Begriff „Datenbank“

bezeichnet

  1. eine strukturierte Sammlung von Daten (= Schema + Tabelleninhalte) und
  2. Mechanismen und Protokolle zur Verwaltung dieser Daten.

SQL

  • SQL ist ein Akronym für Structured Query Language.
  • Erstmals 1974 veröffentlicht,
    seit 1986 ANSI- und seit 1987 ISO-Standard.
  • Vier Hauptfunktionen:
    1. Create (Schlüsselwort INSERT)
    2. Retrieve (Schlüsselwort SELECT)
    3. Update (Schlüsselwort UPDATE)
    4. Delete (Schlüsselwort DELETE)

Kochrezept: Aufbau einer Abfrage

Geschrieben wird von oben nach unten,
ausgeführt in der Reihenfolge der Nummern:

SELECTspalten5
FROMtabelle11
JOINtabelle2 ON ...1
WHEREbedingung2
GROUP BYspalten3
HAVINGbedingung4
ORDER BYspalten6
  • Im WHERE keine Aggregatfunktionen (noch nicht gruppiert), dafür HAVING
  • Ein Alias aus dem SELECT geht im ORDER BY, im WHERE nicht
