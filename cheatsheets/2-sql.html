2Spalten und Zeilen

SELECT bestimmt die Spalten, WHERE die Zeilen. Das Ergebnis ist die Schnittmenge.

SELECT CustomerName, City
FROM Customers
WHERE Country = 'Germany'

5Sortieren und begrenzen

SELECT TOP 5 ProductName, Price  -- SQL Server
FROM Products
ORDER BY Price DESC
LIMIT 5                          -- MySQL, SQLite

ASC aufsteigend (Standard), DESC absteigend. Mehrere Spalten mit Komma: ORDER BY Country, City sortiert nach Land, darin nach Stadt.

6Schreibweise

-- Kommentar bis zum Zeilenende
SELECT ProductName, Price
FROM Products;           -- Semikolon optional

Schlüsselwörter üblicherweise groß, Zeilenumbrüche nur für die Lesbarkeit. Im SQL-Editor zählt Groß-/Kleinschreibung bei Text nicht.

7Aggregatfunktionen

COUNT(*)Anzahl der Zeilen
COUNT(spalte)Anzahl der Werte, die nicht NULL sind
COUNT(DISTINCT spalte)Anzahl der verschiedenen Werte
SUM(spalte), AVG(spalte)Summe, Durchschnitt (nur Zahlen)
MIN(spalte), MAX(spalte)kleinster, größter Wert (auch Text, Datum)

8GROUP BY: eine Zeile pro Gruppe

SELECT Country,
  COUNT(*) AS Kunden
FROM Customers
GROUP BY Country
HAVING COUNT(*) >= 10
Regeln: Jede Spalte im SELECT steht im GROUP BY oder in einer Aggregatfunktion. Mehrere Spalten im GROUP BY: eine Gruppe pro Kombination.

WHERE filtert Zeilen vor dem Gruppieren, HAVING filtert Gruppen danach (Bedingung mit Aggregatfunktion).

9JOIN: Tabellen verknüpfen

JOIN (= INNER JOIN): nur Zeilen mit Partner in beiden Tabellen.

LEFT JOIN: alle Zeilen der linken Tabelle (nach FROM), ohne Partner mit NULL.

SELECT c.CustomerName, o.OrderID
FROM Customers c                  -- c, o: Aliase
LEFT JOIN Orders o
  ON c.CustomerID = o.CustomerID  -- FK = PK
WHERE o.OrderID IS NULL           -- ohne Bestellung

10Beispieldatenbank (Ausschnitt)

PK (Primärschlüssel) identifiziert eine Zeile eindeutig.
FK (Fremdschlüssel) verweist auf den PK einer anderen Tabelle.
Krähenfuß: ein Kunde hat beliebig viele Bestellungen.
Weitere Tabellen: Employees, Shippers, Suppliers, Categories.
